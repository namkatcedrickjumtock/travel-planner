### file structure for travelPlanner demo project.

1. api/  contains the presentation layer. were we wire up all our endpoints with the services methods.
2. cmd/ contains the directory  for the starter entry of the api.
3. internal/ is where the business logic remains.
4. persistence/ is the location where all the methods that interacts with the database.

See Api Documentation [here](https://documenter.getpostman.com/view/31532693/2sBXcDF1Nc)
